# DECA Event Resources

Downloaded from the official DECA competitive-event pages on August 7, 2026.

Each event folder contains `guidelines.pdf`, `statement-of-assurances-and-integrity.pdf`, `penalty-point-checklist.pdf`, and `competition-advice.html` when DECA publishes those resources. `sample-event.pdf` is included when DECA publishes one.

The current site uses these official names for the entrepreneurship folders requested under legacy or alternate labels:

- `IEC`: Innovation Plan (`EIP`)
- `FBP`: Franchise Business Plan (`EFB`)
- `IBPL`: Independent Business Plan (`EIB`)
- `ENIN`: Start-Up Business Plan (`ESB`)

DECA currently lists the statement, penalty checklist, sample-event, and competition-advice links as unavailable for `HTPS`, `PSE`, and `FCE`; their folders therefore contain the available guidelines and shared prepared-event statement only.
